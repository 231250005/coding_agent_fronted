# Coding Agent 前端

编程智能体（coding agent）的本地 Web 前端：通过与后端交互，以对话的方式驱动 agent 读写文件、执行命令、完成任务。后端接口见 [API.md](./API.md)。

基于 **Vue 3 + Vite + Naive UI + Pinia**（JavaScript），纯本地运行，支持深浅双主题（选择持久化）。

## 功能一览

### 工作区管理（左侧栏）

- **新建工作区**：输入任务直接发送即自动创建会话（标题取任务前 30 字）；也可点侧栏按钮进入新会话界面
- **分组展示**：置顶 / 今日 / 一周内 / 一月内 / 更多，组内按最近修改排序，空组自动隐藏
- **置顶 / 重命名 / 删除**：⋮ 菜单操作；置顶的工作区文件夹图标高亮金色；删除时级联清理聊天记录（弹窗明示）
- **运行指示**：任务运行中，该工作区名称后显示绿色脉冲点（切换会话不消失）
- **目录选择**：点击文件夹图标弹出**系统原生文件夹对话框**，选完自动调后端 `resolve` 接口解析绝对路径；同名目录多候选时内联点选

### 对话与实时输出（右侧区）

- **SSE 实时事件流**：思考过程、工具调用与结果、最终回答全部实时呈现
- **流式输出**：思考与最终回答逐字打字机输出（18ms/字），仅任务运行中流式——切换会话切回不重播
- **消息时间**：每条消息下方附相对发送时间（每分钟自动刷新）
- **上下文用量条**：相对 128k 窗口实时显示，超过 100k 压缩阈值变警示色
- **断线/切换恢复**：任务运行中切换会话，消息流快照缓存完整保留；刷新后历史恢复、事件流自动续接

### 三级权限（每次发送可选，选择持久化）

| 模式 | 层级 | 行为 |
|---|---|---|
| 默认模式 | L1 | 每步写/改文件都弹出**确认卡片**（完整 diff 可滚动），确认后才落盘 |
| 代理模式 | L2 | 自动执行，文件变更可对比、可撤销 |
| 自动模式 | L3 | 同 L2，任务完成后自动 git 提交 |

权限下拉面板内置图标 + 单行解释，面向普通用户。

### 文件变更区（输入框上方，上拉栏）

- 展开显示全部变更：新建 / 修改、状态（待确认已不在此处展示，走确认卡片）
- 每个文件支持：**撤销**（还原为变更前；文件被外部修改时 409 冲突弹窗展示 current/expected 差异）、**对比**（红绿交替仅显示差异行，另有旧/新完整内容视图）
- **撤销全部 / 保存全部**：批量操作，保存全部调用后端 `confirm-all` 接口

## 运行

**前置要求**：Node.js 20+（含 npm，官网 https://nodejs.org 下载安装即可）

```bash
npm install        # 安装依赖（首次）
npm run dev        # http://localhost:5173（/api 自动代理到 127.0.0.1:8000）
```

先启动后端（Python 环境），再访问前端即可。API key 等凭据由后端通过环境变量管理，前端不接触。

## 技术要点

- **SSE 生命周期**：终态（task_done/error）手动 `close()`，从根上避免浏览器 3 秒自动重连风暴；发送任务前先建立连接，保证不丢事件；空闲连接失败提供手动重连
- **运行状态双信号判定**：SSE 任务事件 / 后端 400「任务运行中」，不依赖本地猜测；误判时后端 400 响应作为权威依据自动恢复
- **运行中会话切换不丢消息**：后端过程事件不落库、SSE 不重放——前端用内存快照缓存（含流式进度 typedLen），切回恢复现场并续接事件流，不重播已输出内容
- **L1 确认链路**：后端 diff 仅为截断预览（前 10 行），前端用变更列表的完整 old/new 内容重建逐字对比，保证可滚动查看全部差异
- **不引入 diff 库**：`utils/diff.js` 行级解析 + 色带高亮，对比视图红绿交替
- **工作区路径选择**：浏览器安全限制下点击选择器拿不到绝对路径——选完调后端 `resolve` 接口按文件夹名解析；同名多候选前端内联选择
- **主题系统**：设计令牌单一事实源（`styles/theme.js`），Naive UI overrides + CSS 变量双通道注入，深浅主题持久化
- **上下文展示**：UsageBar 分母与后端窗口一致（128k），压缩阈值（100k）警示

## 目录结构

```
src/
├─ api/            # REST / SSE 封装（http 拦截器统一解包错误）
├─ stores/         # Pinia：会话 / 聊天（SSE 生命周期）/ 变更
├─ composables/    # 主题、会话切换编排、弹窗单例
├─ utils/          # diff 解析、时间、格式化
├─ styles/         # 设计令牌（深浅两套）+ 全局样式
└─ components/
   ├─ layout/      # 侧栏（工作区列表 / 会话项 / 删除弹窗）
   ├─ chat/        # 消息流 / 确认卡片 / 变更区 / 输入区
   └─ common/      # 权限徽标 / Diff 视图 / 变更详情抽屉
```
