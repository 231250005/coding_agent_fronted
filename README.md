# Coding Agent 前端

编程智能体（coding agent）的本地 Web 前端，配套后端运行于 `http://127.0.0.1:8000`（接口见 [API.md](./API.md)）。

基于 **Vue 3 + Vite + Naive UI + Pinia**，纯本地运行，支持深浅双主题。

## 功能

- **会话管理**：新建（指定工作目录）/ 置顶 / 重命名 / 删除，置顶优先 + 最近更新排序；会话内工作目录固定
- **快捷开工**：无会话时输入框旁常驻工作目录输入，发送时自动创建会话（标题取任务前 30 字）并执行任务
- **对话与实时输出**：SSE 事件流实时展示 agent 的思考过程、工具调用与结果、最终回答（带头像），上下文用量条实时更新
- **三级权限**（每次发送可选）：
  - **L1** 每步文件修改内嵌 diff 确认卡片，确认后才落盘
  - **L2** 自动执行，变更可对比、可撤销
  - **L3** 同 L2，任务完成后自动 git 提交
- **文件变更区**（输入框上方）：点「文件变更 N」展开文件列表，每个文件支持 撤销 / 对比（原文件与当前文件的差异）/ 待确认时确认与拒绝
- **断线恢复**：刷新页面后历史完整恢复；任务运行中刷新自动接续事件流；L1 待确认变更可在变更区兜底处理

## 运行

```bash
npm install
npm run dev        # http://localhost:5173（/api 自动代理到 127.0.0.1:8000）
```

先启动后端，再访问前端即可。

## 技术要点

- 不引入 diff 库：后端下发 diff 文本，前端 `utils/diff.js` 行级解析 + 色带高亮
- SSE 生命周期：终态（task_done/error）手动 `close()`，从根上避免浏览器 3 秒自动重连风暴；发送任务前先建立连接，保证不丢事件
- 运行中状态双信号判定：SSE 任务事件 / 后端 400「任务运行中」，刷新后不依赖本地猜测
